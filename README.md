# Cairo Airport Digital Twin — Web Command Center

واجهة ويب فقط (Frontend-only) لمركز القيادة الرقمي لمطار القاهرة، مبنية وفق **Master System Blueprint** المكوّن من 32 صفحة، مع الالتزام بتخطيط شاشة `operations_dashboard.png`.

> **تنبيه مهم:** هذا المشروع **واجهة أمامية فقط**. لا يحتوي على خادم خلفي، قاعدة بيانات، مصادقة حقيقية، تدريب نماذج، محرك محاكاة فعلي، أو نشر. كل القيم من بيانات ثابتة (fixtures) موسومة بالمصدر ووقت الرصد والحداثة. لا يوجد أي اتصال بالأجهزة أو الأنظمة الحقيقية.

## 3. ملخص نظام التصميم

- خلفية صفحة سماوية فاتحة (`#F8FBFC`)، بطاقات بيضاء بحدود خفيفة وظل ناعم.
- شريط جانبي داكن في العربية على **اليمين**، ويُنعكس إلى **اليسار** في الإنجليزية (RTL/LTR كامل).
- ألوان: تيل/نيلي للإجراءات، أخضر للسليم، برتقالي للتحذير، أحمر للخطر.
- مسافات موحّدة: 4 / 8 / 12 / 16 / 24 / 32، وأنصاف أقطار بطاقات: 20 / 16 / 12.
- خط **Cairo** للعربية و **Inter** للإنجليزية.
- المعرّفات وأرقام الرحلات والوقت والرموز دائمًا داخل **جزر LTR** (`LtrText`, `IdText`, `Mono`) لمنع انقلاب الاتجاه.
- كل مؤشر/قيمة يعرض: **القيمة + الوحدة + وقت الرصد + نمط المصدر + الحداثة**، وكل KPI قابل للتفصيل.
- الرسوم مخصّصة (`CustomPainter`): المرصود خط متصل، المتوقع متقطع، والمحاكى نطاق ظلّي.
- لا إفراط في التدرّجات أو الزجاج أو التوهج.

### ملاحظة خاصة بمسار المشروع على Windows
مسار المشروع يحتوي على اسم مجلد عربي (`المستندات`). أداة **icon tree shaking** في Flutter على Windows تفشل مع المسارات غير ASCII، لذا بناء الإنتاج يحتاج العلم `--no-tree-shake-icons` (انظر القسم 6). التشغيل التطويري `flutter run` لا يتأثر بذلك.

## 5. خطوات الاختبار على متصفح الجوال

1. شغّل `flutter run -d web-server --web-port=8080`.
2. من نفس شبكة Wi-Fi، افتح على الجوال: `http://<IP-الجهاز>:8080` (يطبع Flutter عنوان الشبكة في الطرفية).
3. جرّب التالي:
   - تبديل اللغة من الشريط الجانبي: العربية (RTL، شريط يمين) ↔ English (LTR، شريط يسار).
   - التأكد أن المعرّفات والوقت لا تنقلب اتجاهاتها.
   - فتح كل شاشة من القائمة، وتجربة الفلاتر والبحث والنقر على الصفوف/KPI.
   - في Digital Twin: تبديل الطبقات واختيار منطقة ثم فحص الكيان.
   - تبديل الدور من شريط المستخدم والتحقق أن الأزرار تُفعّل/تُعطّل حسب المصفوفة.
   - تغيير اتجاه الجوال (Portrait/Landscape) للتأكد من تكيّف الجداول (تمرير أفقي) وال grids.
4. الأخطاء تظهر في تبويب Console في أدوات المطوّر، ولا توجد أخطاء في `flutter analyze`.

## 7. الحدود الحالية (Mock / API)

| البند | الحالة |
|---|---|
| البيانات | كلها `fixtures` ثابتة بساعة مرجعية مجمّدة: **16 Nov 2026 10:24 Cairo (UTC+2)** |
| الواجهات الخلفية | لا يوجد عميل HTTP؛ `TwinRepository` مجرّد عقد (A1–A8) يمكن استبداله بتنفيذ FastAPI لاحقًا دون تغيير الشاشات |
| المصادقة | تسجيل دخول تجريبي باختيار مستخدم؛ لا يوجد خادم هوية أو رموز أو صلاحيات حقيقية |
| الصلاحيات | مصفوفة العرض تخفي/تعطّل الأزرار فقط، وليست حدًّا أمنيًا؛ يجب فرض التخويل على الخادم في النشر الحقيقي |
| الكتابة | الإقرارات والإسنادات والتثبيتات ومفاتيح الأتمتة وطابور السيناريوهات كلها حالة في الذاكرة تختفي عند إعادة التحميل |
| التصدير | زر التصدير يسجّل إدخال تدقيق فقط؛ لا مُولّد PDF/CSV/XLSX |
| النماذج والتنبؤات | مخرجات معروضة من بيانات ثابتة، بنطاقات تقييم بديلة (TSA / حزام مولّد)؛ لا تدريب ولا استدلال حي |
| المحاكاة | منحنيات ونتائج من سيناريوهات ثابتة؛ شريط إعادة العرض بصري فقط ولا يُعيد حساب أي شيء |
| الخرائط | مخطط 2D تخطيطي بمعرفات مناطق ثابتة، ليس خريطة GIS أو تتبّع حي |
| الحداثة | تُ نسخ من كل سجل ولا تُستنتج من وقت فتح الصفحة |
